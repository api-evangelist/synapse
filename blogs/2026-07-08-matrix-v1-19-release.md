Hey all, Matrix 1.19 is here! This release brings 6 more MSCs to the spec since the Matrix 1.18 release just over 3 months ago. Aside from clarifying that server ACLs are case insensitive , adding mutual rooms lookup , and making the room directory order implementation-defined , this release brings a couple of commonly requested features to the protocol: encrypted room history sharing and custom emoji.
